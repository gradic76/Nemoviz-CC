Nemoviz CC – help

Nemoviz CC is a window for talking to Claude, built for screen readers (JAWS and NVDA). Behind it runs Claude Code, which lets Claude work with files and programs on your computer.

First start

The program asks where conversations and projects will live (Documents\Claude by default). The Chat subfolder is for plain conversations; every other subfolder is one project.

If Claude Code is not installed, the program offers to install it. If it is not signed in, choose Help, Sign in to Claude; signing in happens in the browser.

Claude Code needs a Claude subscription (Pro or Max).

The window

From top to bottom:

  • Indicators: Context (how full the conversation is), the 5-hour and weekly limits, and Model, Effort and Permissions, which can be changed.
  • Automatic in the Model and Effort boxes: before each message Claude rates how demanding the task is and picks the effort; the model is chosen on the conversation's first message and can only go up after that. The choice is shown in the Live field while Claude works. You can still choose by hand.
  • Live: what Claude is doing right now. It speaks only while it has the focus. Next to it is the Stop button.
  • History: the whole conversation. Every message starts with a header with a name. It is read with the arrow keys.
  • Message: where you write. Next to it is the Send button.

When Claude finishes an answer, the answer is spoken, unless you are in the Live field, where you have already heard it.

Keys

  • Enter – send. Shift+Enter – new line.
  • Alt+Enter – queue; it is sent when the current answer finishes.
  • Alt+1 to Alt+0 – speak one of the last ten messages (Alt+1 is the latest).
  • In History: H – next message, Shift+H – previous.
  • Alt+H – History. Alt+E – Message. Alt+L – Live.
  • Tab and Shift+Tab – through all fields and buttons.
  • Ctrl+U – attach files to the next message.
  • Ctrl+V – pastes text, and adds files from Explorer and an image as attachments.
  • F1 – this help.
  • F5 – run the project's program.
  • Applications key or Shift+F10: in History, copy a message or code, save a message, open files and folders the message mentions; in Message, editing and attachments.

Menus

File

  • Chat: New chat (title, instructions for the conversation, model, attachments, first message) and past conversations, newest first.
  • Code: New project (a two-step wizard), Open an existing project/chat, and the projects. In each project, New conversation and the conversations, oldest first.
  • Manage projects and conversations: a tree of projects with their conversations, and the list of chats. On each item (menu or the buttons below): Delete hides it, and Open an existing project/chat brings it back; Delete from disk too sends it to the Recycle Bin, after a question; Rename; Show memory; Run program. Enter opens a conversation.
  • Open folder in Explorer, Settings, Exit.

Session

  • Available on the phone: you can also carry on the open conversation from the Claude mobile app, among the Code sessions. What you type on the phone shows up here too, and the same permissions apply. The window must stay open, and the computer does not go to sleep while this is on.
  • New conversation and Choose project folder.
  • Resume after the usage limit resets: when you run out, the window carries on by itself once the limit is renewed.
  • Hand over and open a new conversation: Claude writes down how far you got, then a new, empty conversation opens. This also happens by itself when the context fills up (in Settings).
  • Delete this conversation.
  • Run the project's program (F5) and Change the project's program: you choose the program the first time, and the window remembers it for the project.

Help

  • Help (F1), What's new, Keyboard shortcuts, Sign in to Claude, About.

Settings

File, Settings; Ctrl+Tab changes the tab.

  • General: language, theme, text size, resuming after the limit, when to start a new session, projects folder.
  • Sounds and devices: three sounds (send, answer, working), each with a check box, a Listen button and its volume; speaking sent messages and answers; output device; Keep the device awake (if a TV or HDMI cuts off the start of a sound).
  • Claude: personal instructions (for all conversations and projects) and instructions for chats. This is where you tell Claude how to address you and what answers you want. The Use Claude in Chrome check box lets Claude work in your Chrome; the Claude in Chrome extension must be installed and signed in, in the extension itself, because signing in on the claude.ai site is not enough.

Where things are

  • Conversations: the .claude\projects folder in your user folder, the same as for Claude Code and Claude's desktop app, so conversations show in both.
  • Window settings: %APPDATA%\ClaudeChat (the portable build keeps its settings beside the program).
