Nemoviz CC – what's new

Version 0.1.2, 8 November 2026

  • The Stop button is no longer active and is greyed out while Claude is doing nothing.
  • When the Nemoviz CC window is not in focus, the activity sound is no longer heard and a new answer is not read automatically. Instead you hear the message "Nemoviz CC has answered".
  • The remaining-limit indicators now show the last remembered state as soon as the window opens.
  • The window for managing projects has been redesigned; we believe it is now simpler and more intuitive.
  • Each project can have its own program, started with the F5 key.
