Nemoviz CC – what's new

Version 0.1.3, 9 November 2026

  • The program is now about ten times smaller. It no longer carries its own .NET and uses .NET Framework 4.8, which is already part of Windows, so it needs Windows 10 version 1903 or later.
  • The Model and Effort boxes have a new choice, Automatic: before each message Claude rates how demanding the task is and picks Haiku, Sonnet or Opus and the effort. The model is chosen on a conversation's first message and can only go up after that, because every change of model uses up the limit. The effort is rated with every message.
  • ...And a few things under the hood...

Version 0.1.2, 8 November 2026

  • The Stop button is no longer active and is greyed out while Claude is doing nothing.
  • When the Nemoviz CC window is not in focus, the activity sound is no longer heard and a new answer is not read automatically. Instead you hear the message "Nemoviz CC has answered".
  • The remaining-limit indicators now show the last remembered state as soon as the window opens.
  • The window for managing projects has been redesigned; we believe it is now simpler and more intuitive.
  • Sign in to Claude has moved from the File menu to the Help menu.
  • The development version of the application starts with the F5 key. Development versions of other projects can be started from Manage projects and conversations, through each project's context menu. Your desktop will be tidier.
  • When an answer arrives while the window is not in focus, the Nemoviz CC button on the taskbar flashes until you return to the window.
  • Open an existing folder is now called Open an existing project/chat, and it is also in the Chat submenu. It brings back what was hidden in Manage projects and conversations.
  • There is a new item in the Help menu: What's new.
  • Updating is simpler now: when a new version comes out, you see what is new straight away, and Update downloads and installs everything by itself, with no further questions, and opens the window again. The same goes for the portable version.
